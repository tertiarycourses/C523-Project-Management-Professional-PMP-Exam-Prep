## Examination Content Outline &mdash; July 2026

The July 2026 update rebalanced the exam domains and introduced sustainability and artificial intelligence as examinable considerations.

| Domain | Weighting | Coverage |
| --- | --- | --- |
| I. People | **33%** | How you lead, align and communicate with the humans on and around the project. |
| II. Process | **41%** | How you plan, deliver, measure and close the work itself. |
| III. Business Environment | **26%** | How the project connects to governance, compliance, risk and organisational change. |

**Exam format:** 180 questions (170 scored + 10 unscored pretest) in 240 minutes. Two 10-minute breaks — the first after the case-study section, the second midway through the independent questions. About 40% predictive; the remaining 60% split between adaptive/agile and hybrid.

## Learning Outcomes

- **LO1:** Scope medium-scale project requirements to drive timely completions.
- **LO2:** Develop project plans based on realistic timelines and resource allocations.
- **LO3:** Implement methodologies effectively to address project exigencies and derive solutions from identified root causes.
- **LO4:** Analyze program risks and engage stakeholders through scheduled touchpoints to discuss potential issues.
- **LO5:** Coordinate project deliverables against set objectives, costs, and timelines, and implement corrective actions.

## Problem-Solving Tools

The labs use these browser-based tools. No installation required, and they remain available to learners after the course.

| Tool | Purpose | Link |
| --- | --- | --- |
| 5 Whys | Drill from a symptom to its root cause by asking 'why' five times. | [alfredang.github.io/5whys/](https://alfredang.github.io/5whys/) |
| Fishbone Diagram | Group candidate causes into categories around a problem statement. | [alfredang.github.io/fishbone/](https://alfredang.github.io/fishbone/) |
| Pareto Chart | Rank defect categories to find the vital few driving most of the pain. | [alfredang.github.io/paretochart/](https://alfredang.github.io/paretochart/) |
| System Thinking | Map reinforcing and balancing loops behind a recurring problem. | [alfredang.github.io/systemloop/](https://alfredang.github.io/systemloop/) |
| SPC / Control Chart | Plot a process over time against control limits to separate signal from noise. | [alfredang.github.io/novaspc/](https://alfredang.github.io/novaspc/) |
| Statistics | Descriptive statistics, distributions and hypothesis testing on project data. | [alfredang.github.io/novastats/](https://alfredang.github.io/novastats/) |
| RACI Matrix | Assign Responsible, Accountable, Consulted and Informed per work package. | [alfredang.github.io/raci/](https://alfredang.github.io/raci/) |
| Kanban Board | Visualise work in progress, limit WIP and expose bottlenecks. | [alfredang.github.io/kanban/](https://alfredang.github.io/kanban/) |
| Scrum Simulator | Run sprint planning, review and retrospective mechanics. | [alfredang.github.io/scrum/](https://alfredang.github.io/scrum/) |
| Mind Mapping | Expand a central idea into branches for requirements discovery. | [alfredang.github.io/mindmapping/](https://alfredang.github.io/mindmapping/) |
| Design Thinking | Empathise, define, ideate, prototype and test a solution. | [alfredang.github.io/designthinking/](https://alfredang.github.io/designthinking/) |
| Pivot Analysis | Slice project data by dimension to expose trends and outliers. | [alfredang.github.io/novapivot/](https://alfredang.github.io/novapivot/) |

## Building the Courseware

All artifacts are generated from a single source so they cannot drift apart. `course_data.py` holds the course metadata and the ECO task map; `labs_index.py` is the canonical lab list.

```bash
cd build
python3 build_slides.py         # the slide deck
python3 build_lesson_plan.py    # the Lesson Plan DOCX
python3 build_learner_guide.py  # the Learner Guide DOCX + Markdown mirror
python3 build_readme.py         # this README
python3 verify_alignment.py     # alignment gate across every artifact
```

`verify_alignment.py` fails the build if the deck, Lesson Plan, Learner Guide and labs disagree with each other or with the ECO.
